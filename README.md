# cb2330-project-elowitz

# Intrinsic noise in Elowitz et al. (2002)

CB2330 PRO1. We test whether the paper's fitted noise curve, eta_int^2 = c1/m + c2, is consistent with the
paper's own measurement for strain M22 at full induction (Table 1).

**Result:** the paper's curve predicts eta_int = 0.061 at m = 1, while the measured value is
0.055 (95 % CI 0.051–0.060): 2.5 standard deviations away (p ≈ 0.6 %).

**Run:** `pip install matplotlib`, then open `project.ipynb` and Run All.
